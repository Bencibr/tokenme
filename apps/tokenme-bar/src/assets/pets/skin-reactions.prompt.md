# Companion reaction atlases

Generated with the built-in image_gen tool using each skin's base sprite atlas as its identity and style reference. Final delivery files are `han-girl-reactions-v1.webp`, `han-boy-reactions-v1.webp`, `modern-girl-reactions-v1.webp`, `summer-beauty-reactions-v1.webp`, `pure-summer-beauty-reactions-v1.webp`. Original generated PNGs remain in the tool's image archive. WebP delivery uses quality 100, preserves native dimensions and the alpha channel exactly; it does not change poses or artwork. Each square atlas has hello, care, sleep and stretch in reading order. The classic waterdrop remains code-native and uses CSS expressions.
